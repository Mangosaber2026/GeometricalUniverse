GeometricalDominaton provides premade-drawings created by the developer and a collection of base shapes, English letters, etc. with which the user can create their own designs/patterns.

GeometricalUniverse

GeometricalUniverse utilizes several programming languages and technologies, each selected according to its intented purpose and the requirements of individual projects.

Python

Python serves as the primary language for GeometricalUniverse's core libraries, providing the foundation for geometric executions, reusable utilities, and turtle graphics.

PowerShell

PowerShell is required for Windows related automation, development workflows, environment validation, and managing various operations throughout the ecosystem.

TypeScript

TypeScript provides a statically typed development environment for reusable utilities, development tooling, and other infrastructure surrounding the Python projects which require static typing.
