## Overview

This module contains the class [`EngPunctuation`](../english_punctuations.py) which contains functions to draw some common English punctuation. 

## Classes

### EngPunctuation
---

This class contains functions to draw some common English punctuations.

These take 2 arguments: height -> height of the punctuation, tls_num -> the turtle each punctuation is supposed to be drawn with, the color of the punctuation is the color of the provided turtle.

All functions are accessible through [`EngAlphabets`](english_alphabets.md#engalphabets).
