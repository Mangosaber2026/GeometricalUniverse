## Overview

This module contains a validator function for the parameters of all English alphabet functions and a decorator to apply to the functions.

## Functions (validators)

### alphabets_validate
---

This function takes the parameters "height" and "tls_num" and validates them against their expected type.

## Functions (decorators)

### alphabets_deco
---

This function decorates any function that accepts the parameters "height", which is expected to be either a num.Real, int or float, and "tls_num", which is expected to be a [ChainTurtle instance](https://github.com/Mangosaber2026/TurtleExtension/blob/main/turtle_extension/turtle_heart/turtle_skeleton.py) and validates them against their expected type with [`alphabets_validate`](english_alphabets_validators.md#alphabets_validate).
