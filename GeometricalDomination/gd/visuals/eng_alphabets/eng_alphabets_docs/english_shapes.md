## Overview

This module contains the class [`EngShapes`](../english_shapes.py) which contains functions to draw some mathematical symbols and some shapes beside [`letters`](english_letters.md#engletters) and [`punctuation`](english_punctuations.md#engpunctuation).

## Classes

### EngShapes
---

This class contains functions to draw some mathematical symbols and some shapes beside text.

These take 2 arguments: height -> height of the symbol/shape, tls_num -> the turtle each symbol/shape is supposed to be drawn with, the color of the symbol/shape is the color of the provided turtle.

All functions are accessible through [`EngAlphabets`](english_alphabets.md#engalphabets).
