# UniversalTSFunctions

Reusable TypeScript utilities for the GeometricalUniverse ecosystem.

## ConsoleToolkit

Terminal-oriented console output utilities.

```typescript
import { ConsoleToolkit } from "universal-ts-functions";

ConsoleToolkit.success("Operation completed!");
ConsoleToolkit.warning("Something needs attention.");
ConsoleToolkit.error("Operation failed.");
ConsoleToolkit.information("Checking environment...");
```
