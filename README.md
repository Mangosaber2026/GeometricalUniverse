# GeometricalUniverse

The central development ecosystem of Mangosaber2026.

GeometricalUniverse brings together Python libraries, development
tooling, web projects, and experiments under one Git repository.

## Projects

### Python libraries

- **GeometricalDomination** — Turtle graphics library and DSL.
- **UniversalFunctions** — Foundational utility functions.
- **TurtleExtension** — Extensions to Python Turtle graphics.

Each library maintains its own version number and independent PyPI release process.

### Development tools

- **GD_Toolkit** — TypeScript development toolkit.

### Website

- **mangosaber2026.github.io** — Personal website and web application.

### Experiments

- Experimental projects and research.

## Independent releases

Python package releases use separate Git tag namespaces:

- `gd-vMAJOR.MINOR.PATCH`
- `uf-vMAJOR.MINOR.PATCH`
- `tx-vMAJOR.MINOR.PATCH`

Each release builds and publishes only its corresponding Python package.

## Development

The repository uses two primary branches:

- `main` — Stable development.
- `experimental` — Active development.
